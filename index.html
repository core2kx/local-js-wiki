      Folder saving is turned off in this browser

      Brave turns off the browser feature LocalWiki uses to save into a folder (the File System Access API). You can turn it on:

      1. Open a new tab and go to
      2. Set File System Access API to Enabled. (If the address does not jump to it, search the page for "File System Access".)
      3. Click Relaunch, then choose Open folder again.

      Until then you can open a folder read-only and keep your changes with Export wiki ZIP…

      Problems found while opening

      The rest of the wiki loaded normally. Set-aside files are never changed or deleted; fix them in a text editor, then open the folder again.
