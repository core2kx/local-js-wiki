        Folder saving is turned off in this browser

        Brave turns off the browser feature this app uses to save into a folder (the File System Access API). You can turn it on:

        1. Open a new tab and paste this address:
        2. Set File System Access API to Enabled. (If the address does not jump to it, search the page for "File System Access".)
        3. Click Relaunch, then choose Open folder again.

        Until then you can open a folder read-only and keep your changes with Export wiki ZIP…
